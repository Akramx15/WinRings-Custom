# WinRings-Custom — Known Issues & Resolutions (`v3.0.1.0`)

Record of all issues tracked during v2.0.1 testing (from Obsidian notes) and how they were diagnosed and fixed in `v3.0.1.0`.

| # | Reported Issue | Root Cause | Resolution in `v3.0.1.0` |
| :-: | :--- | :--- | :--- |
| **1** | **Media Island overlaps System Tray icons when many tray icons are open** | Static horizontal clamp assumed a fixed 26% right reserve, which was narrower than crowded `SystemTrayFrame` widths on `1280x800`. | Exposed `XamlTaskbarCtrl::GetSystemTrayWidthDip()` + tray metrics callback, dynamically clamped/shifted Media Island left of the live tray width (shrinking progressively if needed), added `Alt+Drag` horizontal persistence (`mediaIslandOffsetXPct`), and added **Reset Island Position**. |
| **2** | **Media Island stays visible during fullscreen YouTube / browser videos** | `SHQueryUserNotificationState` (`QUNS_RUNNING_D3D_FULL_SCREEN`) misses browser fullscreen videos where `Shell_TrayWnd` stays behind the fullscreen browser in Z-order. | Implemented Z-order + monitor coverage fullscreen detection synced with taskbar visibility and added 3 user modes (`SyncWithTaskbar`, `GamesOnly`, `NeverHide`) polled lightly every `350ms`. |
| **3** | **Toggle shortcut to show/hide Media Island quickly** | No right-click or tray toggle existed when temporarily wanting a clean top bar. | Added `Show Media Island` to the Host tray menu, Ring right-click menu, Media Island context menu (`Hide Media Island`), and CLI `--toggle-media-island`. |
| **4** | **Scroll wheel volume over Media Island didn't respond** | `WS_EX_NOACTIVATE \| WS_EX_TOOLWINDOW` popups do not receive `WM_MOUSEWHEEL` reliably (especially 2-finger precision touchpad scroll). | Intercepted `WM_MOUSEWHEEL` inside `InputEngine` (`WH_MOUSE_LL`) when hovering `MediaIsland::HitTestScreenPoint(pt)` and routed via `PostExternalWheel`, adjusting master volume by `±0.02` per `60` delta with MTA/STA-safe COM cleanup. |
| **5** | **Grain / black ring artifacts when blur disabled or on older v2 compositor** | Upstream v2 compositor edge bug + synthetic noise brush (`useNoise`) continued drawing over solid fills even when `disableRingBlur = true`. | Merged upstream `v3.0.0` `WCA` Acrylic + 3D bevel fixes and guarded `m_wcaBackdropHwnd`, `m_acrylicBackdrop`, and `useNoise` strictly behind `!m_config.disableRingBlur` in both `RingOverlay.cpp` and `SettingsDialog.cpp`. |
| **6** | **Mouse shake occasionally stops working after Explorer reload or transient cursor hide** | `GestureEngine` dropped shakes when `QUNS_BUSY` coincided with `CURSOR_SHOWING == 0`, and `WinRingsHost.cpp` did not reset `g_runtime.retryIndex` on `TaskbarCreated`. | Removed the false `QUNS_BUSY && !CURSOR_SHOWING` suppression in `GestureEngine.cpp` and reset `g_runtime.retryIndex = 0` inside `WinRingsHost.cpp` on `TaskbarCreated`. |
