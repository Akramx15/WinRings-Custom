# WinRings-Custom — Known Issues & Resolutions (`v3.0.4.0`)

Record of all issues tracked from Obsidian notes and live user testing across `v3.0.1.0` through `v3.0.4.0`.

## Fixed in `v3.0.4.0`

| # | Reported Issue | Root Cause | Resolution in `v3.0.4.0` |
| :-: | :--- | :--- | :--- |
| **1** | **Open-Shell steals `Win` key again after reboot** | Open-Shell `4.4.198` (`{E7FAF594-3859-4121-9030-EDB2880E562F}`) stayed installed with `HKLM\...\Run` launching `StartMenu.exe -autorun` and resetting `HKCU\Software\OpenShell\...\WinKey = ClassicMenu` on boot. | Permanently uninstalled Open-Shell via MSI and removed `HKLM`/`HKCU` Run entries, `HKCU\Software\OpenShell`, and the installation folder; updated `Deploy-WinRings.ps1` with ongoing Open-Shell autostart/directory cleanup hygiene. |
| **2** | **Mouse Shake stops working after reboot (and with Precision Touchpad / UAC)** | `InputEngine::HandleMouse` reset shake state on every `LLMHF_INJECTED` packet (dropping Precision Touchpad cursor events), cached `m_lbtnHeld/m_rbtnHeld/m_mbtnHeld` could wedge on missed UAC/suppressed `WM_*BUTTONUP`, and `Arm()` installed LL hooks before heavy boot init without silent hook-eviction recovery. | Distinguished `selfInjected` (`kWinRingsInjectedTag`) from OS Precision Touchpad packets, replaced cached button flags with live `GetAsyncKeyState`, moved `m_input.Install` after heavy module init, and added cursor-heartbeat hook eviction detection + `ReinstallHooks()` in `ShellController`. |
| **3** | **Top-Right Touchpad corner tap stops triggering** | On `ELAN06FA` hybrid serial HID reports, `ContactCount == 0` continuation reports for extra fingers overwrote `prevTipDown`, missed lift reports across idle/UAC wedged state, corner tolerances (`0.05` / `260 ms`) were overly strict, and transient boot `GetRawInputDeviceInfoW` failures were permanently cached. | Added `remainingContinuationReports` frame tracking, `350 ms` idle state reset, pure `IsNormalizedPointInTouchpadCorner` math with practical (`0.10` / `380 ms`) tolerances, transient-failure non-caching in `GetOrInspectTouchpad`, and RawInput cache reset on recovery. |
| **4** | **Search Arc right-click fell back to general menu** | `RingOverlay::ShowContextMenuAt` only checked `card.window` and called `ClearSubmenu()` immediately before inspecting Search Arc `subSlot` cards. | Hit-tested submenu cards via `HitTestSubmenu(localDip)` before clearing, added `Run as Administrator` and `Open File Location` (`SlotModel::ResolveShortcutTarget`, `SlotModel::LaunchRunAsAdmin`, enhanced `SlotModel::RevealInExplorer` for `.lnk` & UWP/KnownFolder AUMIDs) while preserving the Search Arc on dismiss. |

## Fixed in `v3.0.3.0`

| # | Reported Issue | Root Cause | Resolution in `v3.0.3.0` |
| :-: | :--- | :--- | :--- |
| **1** | **Dragged window stayed frozen in place until hitting screen edge** | Because `WM_LBUTTONDOWN` originated inside `RingOverlay` (`explorer.exe`), cross-process `PostMessageW(targetHwnd, WM_SYSCOMMAND, SC_MOVE \| 0x0002)` never entered `GUI_INMOVESIZE`, falling back to a ghost preview without moving `m_fallbackTargetHwnd`. | Removed cross-process `SC_MOVE` probing and implemented decoupled ~60Hz `SetWindowPos(..., SWP_NOSIZE \| SWP_NOZORDER \| SWP_NOACTIVATE \| SWP_ASYNCWINDOWPOS)` live window tracking (`kMsgLiveDragMove` + `14 ms` coalesce/flush timer), adding virtually zero CPU/RAM while letting windows glide live under the cursor across edges and free desktop placement. |
| **2** | **First click after Drag-to-Snap Right/Left felt like clicking thin air ("ضغطتين")** | Two causes combined: (1) `InputEngine::HandleMouse` returned `1` on `WM_LBUTTONUP` (swallowing the mouse-up event synchronously inside `WH_MOUSE_LL`), leaving button state out of sync; (2) `Win + Left/Right` opened Windows 11 Snap Assist (`XamlExplorerHostIslandWindow`), stealing focus so Click #1 only dismissed Snap Assist. | Stopped swallowing `WM_LBUTTONUP` in `InputEngine.cpp` (`ResetTransientState` also queries real `GetAsyncKeyState` button bits) and deferred release handling cleanly via `kMsgLiveDragRelease`; made **Direct Pixel-Perfect Snap** (`ApplyDirectSnap` + `DWMWA_EXTENDED_FRAME_BOUNDS` border compensation + immediate `BringWindowForeground`) the default (`dragToSnapUseSnapAssist = false`), with a Settings checkbox to re-enable `Win + Arrow` Snap Assist if desired. |

## Fixed in `v3.0.2.0`

| # | Reported Issue | Root Cause | Resolution in `v3.0.2.0` |
| :-: | :--- | :--- | :--- |
| **1** | **Mouse Shake stops working after opening Volume / Quick Settings flyout** | Per-process `RegisterRawInputDevices` (`0x01/0x02`) inside `explorer.exe` can be overwritten or removed silently when XAML flyouts / File Explorer call `RegisterRawInputDevices`, while `m_mouseRegistered` remained `true` and RawInput handlers ran heavy APIs per mouse packet. | Moved 2D Mouse Shake detection into `InputEngine` (`WH_MOUSE_LL` fixed array, cached DPI scale, zero Win32 API calls per pixel, async `PostMessageW` trigger), and added `GestureEngine::EnsureDeviceRegistration()` (`GetRegisteredRawInputDevices`) on the 1s watchdog timer to auto-recover `hotCorner` and `touchpad HID` registration. |
| **2** | **Scroll over Media Island didn't change volume (Precision Touchpad & top screen edge)** | Precision Touchpad 2-finger scroll bypasses `WH_MOUSE_LL` (`DirectManipulation`/`WM_POINTERWHEEL` or `RIM_TYPEHID`), and hovering the extreme top edge (`y = 0..1`) fell outside the `24px` pill rect (`dstY = 2`). | Expanded `MediaIsland::HitTestScreenPoint` vertically across `monTop .. monTop + barPx`, handled `WM_NCHITTEST` (`HTCLIENT`) + `WM_POINTERWHEEL` + `kMsgExternalWheel` + `kMsgTouchpadWheel` (80ms dedupe, `1%` smooth steps via `kWheelStepThreshold = 30`), and routed `ELAN06FA` 2-finger HID vertical scroll inside `GestureEngine::ProcessHidRaw`. |
| **3** | **Feature: Drag-to-Snap / Split-Screen directly from Ring icons & Window cards** | Previously, dragging outside the Ring only supported file `OLE Drag-Out` or pinned reorder inside the ring. | Added `WindowSnapCtrl`: dragging an unpinned running slot or outer-arc window card—or tearing off a pinned slot outside `outerRadius + dragToSnapTearOffDip`—restores & attaches the target window under the cursor (`SC_MOVE`, falling back to a Fluent edge ghost preview + `Win+Left/Right/Up` on release if `GUI_INMOVESIZE` declines) and optionally launches + auto-snaps closed pinned apps (`HSHELL_*` event-driven, no polling). |

## Previously Resolved in `v3.0.1.0`

| # | Reported Issue | Root Cause | Resolution in `v3.0.1.0` |
| :-: | :--- | :--- | :--- |
| **1** | **Media Island overlaps System Tray icons when many tray icons are open** | Static horizontal clamp assumed a fixed 26% right reserve, which was narrower than crowded `SystemTrayFrame` widths on `1280x800`. | Exposed `XamlTaskbarCtrl::GetSystemTrayWidthDip()` + tray metrics callback, dynamically clamped/shifted Media Island left of the live tray width (shrinking progressively if needed), added `Alt+Drag` horizontal persistence (`mediaIslandOffsetXPct`), and added **Reset Island Position**. |
| **2** | **Media Island stays visible during fullscreen YouTube / browser videos** | `SHQueryUserNotificationState` (`QUNS_RUNNING_D3D_FULL_SCREEN`) misses browser fullscreen videos where `Shell_TrayWnd` stays behind the fullscreen browser in Z-order. | Implemented Z-order + monitor coverage fullscreen detection synced with taskbar visibility and added 3 user modes (`SyncWithTaskbar`, `GamesOnly`, `NeverHide`) polled lightly every `350ms`. |
| **3** | **Toggle shortcut to show/hide Media Island quickly** | No right-click or tray toggle existed when temporarily wanting a clean top bar. | Added `Show Media Island` to the Host tray menu, Ring right-click menu, Media Island context menu (`Hide Media Island`), and CLI `--toggle-media-island`. |
| **4** | **Scroll wheel volume over Media Island didn't respond** | `WS_EX_NOACTIVATE \| WS_EX_TOOLWINDOW` popups do not receive `WM_MOUSEWHEEL` reliably (especially 2-finger precision touchpad scroll). | Intercepted `WM_MOUSEWHEEL` inside `InputEngine` (`WH_MOUSE_LL`) when hovering `MediaIsland::HitTestScreenPoint(pt)` and routed via `PostExternalWheel`, adjusting master volume by `±0.02` per `60` delta with MTA/STA-safe COM cleanup. |
| **5** | **Grain / black ring artifacts when blur disabled or on older v2 compositor** | Upstream v2 compositor edge bug + synthetic noise brush (`useNoise`) continued drawing over solid fills even when `disableRingBlur = true`. | Merged upstream `v3.0.0` `WCA` Acrylic + 3D bevel fixes and guarded `m_wcaBackdropHwnd`, `m_acrylicBackdrop`, and `useNoise` strictly behind `!m_config.disableRingBlur` in both `RingOverlay.cpp` and `SettingsDialog.cpp`. |
| **6** | **Mouse shake occasionally stops working after Explorer reload or transient cursor hide** | `GestureEngine` dropped shakes when `QUNS_BUSY` coincided with `CURSOR_SHOWING == 0`, and `WinRingsHost.cpp` did not reset `g_runtime.retryIndex` on `TaskbarCreated`. | Removed the false `QUNS_BUSY && !CURSOR_SHOWING` suppression in `GestureEngine.cpp` and reset `g_runtime.retryIndex = 0` inside `WinRingsHost.cpp` on `TaskbarCreated`. |
